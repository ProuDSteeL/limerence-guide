Как посмотреть свои карточки

Отправьте /cards.

Limerence покажет сохранённую коллекцию. Активная в текущей Теме карточка будет отмечена.

Из этого же меню можно:

  • выбрать другого персонажа;
  • создать новую карточку;
  • перейти в режим без карточки;
  • открыть управление сохранёнными карточками.

Играть вообще без карточки

Это тоже нормальный вариант.

Откройте /cards и выберите «🚫 Без карточки (freeform RP)».

После этого отдельная Character Card для этой Темы использоваться не будет.

Например, можно полностью описывать персонажей внутри пользовательского промпта.

Для сложных историй с большим количеством NPC это иногда даже удобнее, чем пытаться уместить всё в одну карточку.

Смена карточки в уже начатой истории

Карточку можно переключить через /cards, но важно понимать: смена карточки не стирает уже сыгранную историю.

Например:

  1. вы провели длинный отыгрыш с Адрианом;
  2. затем выбрали карточку Виктора;
  3. история и её память при этом остаются.

Из-за этого события и информация из предыдущего отыгрыша могут продолжить влиять на новую карточку.

Если нужен полностью чистый старт с другим персонажем, лучше создать отдельную Тему либо использовать /clear, а затем выбрать новую карточку.

Управление сохранёнными карточками

Откройте /cards и нажмите «⚙️ Изменить / удалить / экспорт».

Для каждой карточки доступны основные действия.

✏️ Переименовать — меняет имя карточки в вашей коллекции.

Это удобно, например, если несколько вариантов одного персонажа нужно назвать «Адриан — канон» и «Адриан — AU».

⬇️ Экспортировать — Limerence создаст JSON-файл Tavern Character Card.

Его можно сохранить как резервную копию или импортировать в совместимый сервис.

🗑 Удалить — удаляет карточку из коллекции.

Limerence сначала попросит подтверждение.

Если удалённая карточка была активна в каких-либо Темах, они перейдут в режим без карточки.

Сама сыгранная история от удаления карточки не исчезает.

🃏 /cards

Открывает коллекцию Character Cards.

Через неё можно:

  • выбрать персонажа для текущей Темы;
  • перейти в свободный режим без карточки;
  • управлять сохранёнными карточками;
  • создавать новые.

Сами карточки хранятся на уровне аккаунта.

Но активная карточка выбирается для конкретной истории.
