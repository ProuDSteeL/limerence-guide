Первая часть — «Кабинет Limerence: обзор, истории и настройки» — разбирает вход в Кабинет, экран Обзора и все настройки конкретной истории. Здесь продолжаем с персон игрока и карточек персонажей.

👤 Управление персонами через Кабинет

Вернёмся на главный экран.

Откройте «Обзор» → «Персоны».

Здесь отображаются сохранённые персоны игрока.

Персона, которая назначена основной, помечается «по умолчанию».

Создание новой персоны

Нажмите «➕ Создать».

Нужно заполнить:

  • Имя — до 64 символов.
  • Описание — до 4096 символов.

Например:

«Алиса Моррис» «24 года. Реставратор. Короткие светлые волосы, зелёные глаза. Любопытная, упрямая, не любит показывать страх.»

После создания персона появится в общем списке и её можно будет назначить конкретной истории.

Редактирование персоны

Нажмите на существующую персону.

Можно изменить имя и описание.

После сохранения изменения используются Limerence.

Что пока удобнее делать через /profile

Текущий редактор Кабинета ещё не содержит абсолютно все действия /profile.

Например, управление персоной по умолчанию и некоторые операции с коллекцией пока остаются в интерфейсе бота.

То есть:

  • создать и отредактировать → можно в Кабинете;
  • назначить конкретной истории → можно в Кабинете;
  • для полного управления коллекцией по-прежнему доступен /profile.

🃏 Карточки персонажей

Третья основная вкладка — «Карточки» — показывает вашу коллекцию Character Cards.

Карточку можно открыть для полноценного редактирования.

Также можно создать новую прямо в Кабинете.

Создание карточки в Кабинете

Нажмите «➕ Новая карточка».

Редактор здесь заметно подробнее простого мастера /newcard.

Можно заполнить:

  • имя;
  • описание;
  • личность;
  • сценарий;
  • первое сообщение;
  • примеры диалогов;
  • системный промпт карточки;
  • инструкции после истории;
  • заметки автора карточки;
  • версию;
  • автора;
  • теги;
  • альтернативные приветствия.

То есть Кабинет уже подходит не только для простой анкеты, но и для ручного редактирования довольно подробных Tavern Character Cards.

Имя

Поле «Имя» — до 60 символов.

Это обязательное поле при создании новой карточки.

Описание

Описание обычно содержит:

  • кто это;
  • внешность;
  • возраст;
  • биографические сведения;
  • роль персонажа.

Личность

В поле «Личность» можно подробно описать:

  • характер;
  • привычки;
  • мотивацию;
  • манеру речи;
  • отношение к людям;
  • эмоциональные особенности.

Сценарий

Сценарий задаёт исходные обстоятельства карточки.

Например:

«{{user}} недавно устроилась работать в книжный магазин Адриана. Они почти не знают друг друга.»

Это часть самой Character Card, а не общая память вашей текущей истории.

Первое сообщение

Здесь находится стартовое приветствие персонажа.

Например:

«Адриан отложил книгу и посмотрел на вошедшую девушку поверх очков.
— Магазин закрывается через пять минут.»

Если карточка используется для новой истории, первое сообщение может стать её стартовой сценой.

Примеры диалогов

Поле «Примеры диалогов» позволяет хранить образцы речи и поведения персонажа.

Оно особенно полезно для сторонних Tavern-карточек, где автор хочет показать модели: «не только какой персонаж на словах, но и как он реально разговаривает.»

Системный промпт карточки

Некоторые продвинутые Character Cards содержат собственный System Prompt.

Он является частью карточки и может задавать дополнительные правила работы именно с этим персонажем.

Не путайте его с пользовательским промптом всей истории. Это разные уровни конфигурации.

Инструкция после истории

Поле «Инструкция после истории» соответствует продвинутому Tavern-полю Post-History Instructions.

Такая инструкция располагается ближе к текущему хвосту диалога и может использоваться автором карточки для:

  • поддержания характера;
  • контроля стиля;
  • анти-повторов;
  • других важных правил.

Если вы импортировали сложную стороннюю карточку, не стоит удалять это поле только потому, что его название звучит как бухгалтерская форма №17.

Автор мог специально рассчитывать на него.

Заметки автора карточки

Creator Notes — дополнительная информация, оставленная автором карточки.

Она может содержать:

  • рекомендации;
  • описание задумки;
  • рекомендуемую модель;
  • особенности использования;
  • другую метаинформацию.

Версия и автор

Можно отдельно указать версию карточки и автора.

Это удобно, если вы храните разные редакции одного персонажа или переносите карточки между сервисами.

Теги

Карточке можно добавить теги через запятую.

Например: «фэнтези, вампиры, romance, slowburn».

Теги являются метаданными карточки и помогают её организовывать.

Альтернативные приветствия

В Кабинете можно добавлять, редактировать и удалять дополнительные стартовые сообщения.

Нажмите «+ Добавить приветствие».

Можно создать до 20 новых альтернативных приветствий через текущую форму.

Если импортированная старая карточка уже содержит больше, Кабинет не должен обрезать существующие записи только из-за открытия редактора.

Редактирование импортированной карточки

Кабинет подходит не только для карточек, созданных внутри Limerence.

Если вы импортировали Tavern-карточку через PNG или JSON, её текстовые поля можно открыть и изменить здесь.

Это очень удобно для ситуаций:

  • «карточка хорошая, но хочется переписать её personality;»
  • «исправить стартовую сцену;»
  • «добавить example dialogue;»
  • «изменить post-history instruction;»
  • «добавить альтернативный greet.»

После сохранения обновляется сохранённая карточка Limerence.

Импорт PNG и JSON пока выполняется через бота

Текущий Кабинет умеет:

  • создавать карточки вручную;
  • читать существующие;
  • редактировать;
  • удалять.

Но загрузка готового Character Card-файла пока выполняется через Telegram: /import или отправкой подходящего PNG/JSON в игровую группу.

После импорта карточка появится во вкладке «Карточки» и её уже можно спокойно редактировать через Кабинет.

Удаление карточки

Внизу редактора существующей карточки есть «🗑 Удалить карточку».

Перед удалением появится подтверждение. Удаление необратимо.

Если карточка была назначена какой-либо истории, Limerence снимает эту привязку.

При этом сама сыгранная история не удаляется.

👤 Персона текущей истории

В настройках Темы отображается активная персона игрока.

Можно нажать «Выбрать» и назначить одну из сохранённых персон именно этой истории.

Если используется отдельная персона для Темы, рядом будет соответствующая отметка.

Кнопка «Снять» убирает индивидуальный выбор.

После этого Limerence снова может использовать персону по умолчанию.

📚 Лор

Кабинет показывает карточки лора текущей истории.

Для каждой записи можно увидеть:

  • название;
  • несколько ключей;
  • пометку «всегда», если запись постоянная;
  • включена она сейчас или выключена.

Переключателем можно быстро включить или выключить конкретную карточку.

Что пока нельзя делать с лором в Кабинете

Текущая версия показывает существующие записи и позволяет управлять их активностью.

Для полноценного редактирования лора всё ещё используйте /lore.

Через бота сейчас выполняются, например:

  • создание новой карточки;
  • изменение её текста;
  • изменение ключей;
  • значимость;
  • постоянное добавление;
  • импорт World Book;
  • загрузка больших .txt и .md;
  • работа с библиотекой книг;
  • экспорт.

То есть Кабинет уже удобен как быстрый переключатель лора, но пока не является полным редактором lorebook.

Это один из тех разделов, которые ещё будут развиваться.
