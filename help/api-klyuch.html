Подключить свой API-ключ (/api)

Чтобы начать играть в Limerence, свой API-ключ не обязателен. Во время пробного периода можно сразу использовать DeepSeek на ключе Limerence — до 50 ходов в день в течение 7 дней.

Если хочется выбрать другую модель — Claude, Gemini, GPT или любую другую доступную у вашего провайдера — можно подключить собственный API-ключ.

Если собственного API-ключа нет, в новой истории Limerence автоматически может использовать пробный DeepSeek. В старой Теме бот при необходимости предложит кнопку «🎁 Включить DeepSeek-режим».

Если подключить собственный API-ключ, лимит в 50 ходов DeepSeek на игру через этот ключ не распространяется. При этом ограничения и стоимость самого API-провайдера зависят уже от него.

После окончания 7-дневного пробного периода для продолжения работы Limerence потребуется Premium — в том числе если вы играете через собственный API-ключ.

Что такое API-провайдер

API-провайдер — сервис, через который Limerence получает доступ к моделям.

Например, один провайдер может давать доступ сразу к Claude, Gemini, GPT, DeepSeek и другим моделям.

У провайдера обычно есть три вещи:

  • API URL — адрес, по которому Limerence обращается к сервису;
  • API-ключ — секретный ключ вашего аккаунта;
  • ID модели — точное название модели, которую нужно вызвать.

Подписка Limerence и расходы у API-провайдера — разные вещи. Если вы используете собственный ключ, запросы к модели оплачиваются по правилам выбранного провайдера.

Как подключить свой API-ключ

Откройте свою игровую группу и отправьте /api.

Нажмите «➕ Добавить нового».

Limerence предложит продолжить настройку в личной переписке с ботом. Это сделано специально: API-ключ не нужно отправлять в групповом чате.

Дальше бот проведёт через три шага.

Шаг 1. Укажите API URL

Введите адрес API своего провайдера.

Обычно он заканчивается на /v1.

Для некоторых популярных сервисов Limerence уже показывает готовые варианты:

Провайдер API URL
LiteRouter https://api.literouter.com/v1
OpenRouter https://openrouter.ai/api/v1
CometAPI https://api.cometapi.com/v1
OpenAI https://api.openai.com/v1

Можно использовать и другой сервис, если он предоставляет совместимый API.

Важно указывать именно адрес API, а не обычный адрес сайта провайдера.

Шаг 2. Назовите ключ

Введите любое удобное название. Например: Основной, OpenRouter, Claude, Резерв.

Это название видно только вам и помогает различать несколько подключённых провайдеров.

Шаг 3. Отправьте API-ключ

Скопируйте ключ из кабинета своего провайдера и отправьте его боту одним сообщением.

Limerence:

  • удалит сообщение с ключом после получения;
  • проверит, отвечает ли провайдер;
  • сохранит ключ в зашифрованном виде.

Если это первый добавленный провайдер, он автоматически станет основным.

После успешного добавления вернитесь в игровую Тему.

Как изменить или удалить API-ключ

Откройте /api.

Через «✏️ Редактировать» можно изменить:

  • название;
  • API URL;
  • сам API-ключ;
  • назначение провайдера.

Через «❌ Удалить» можно удалить сохранённый провайдер.

Будьте внимательны: если удалить ключ, который используется текущими историями, они не смогут продолжить игру через него, пока вы не выберете другой.

Частые проблемы

«Сначала выбери модель для этой истории» API-ключ уже есть, но для Темы не указана модель. Откройте /settings → «Модель игры» и отправьте точный ID модели.

«Нужен API-ключ для игры» У истории есть модель, но Limerence не нашёл подходящий провайдер. Откройте /api и добавьте ключ либо проверьте /settings → «Ключ игры (эта тема)».

Ключ недействителен Провайдер отклонил авторизацию. Проверьте, что:

  • ключ скопирован полностью;
  • в нём нет пробелов или лишнего текста;
  • ключ не был удалён или отозван в кабинете провайдера.

«Нет баланса / исчерпана квота» Ключ работает, но сам провайдер не разрешает новые запросы. Проверьте баланс и лимиты в кабинете API-провайдера.

Провайдер недоступен или неверный API URL Проверьте адрес API. Очень частая ошибка — вставить адрес обычного сайта вместо API или забыть /v1.

Модель не найдена Провайдер не знает указанный ID модели. Не угадывайте название модели вручную: скопируйте точный ID из документации или списка моделей вашего провайдера. Одинаковая модель у разных сервисов может называться по-разному.

Закончились 50 пробных ходов DeepSeek Пробный DeepSeek даёт до 50 ходов в день. Новый дневной лимит появится в 00:00 МСК. Если хочется продолжить раньше, можно подключить собственный API-ключ.

Для самого простого старта ничего подключать не нужно: создайте Тему и используйте пробный DeepSeek.

Собственный API-ключ имеет смысл подключать, когда вы хотите выбрать другую модель, использовать конкретного провайдера или не зависеть от дневного лимита пробного DeepSeek.

🔑 /api

Открывает управление API-провайдерами.

Можно:

  • добавить свой провайдер;
  • сохранить API-ключ;
  • посмотреть подключённые ключи;
  • выбрать активный;
  • удалить ненужный.

Сам ввод секретного API-ключа переводится в личный чат с ботом.

После подключения модель для конкретной истории выбирается через:

/settings
