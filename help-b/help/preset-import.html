Импорт, включение и хранение пресета

Как импортировать пресет

Отправьте .json с Chat Completion Preset в игровую группу.

Limerence распознает, что это именно generation preset, и покажет предпросмотр.

В предпросмотре можно увидеть, например: название, количество промптов, количество активных блоков, сэмплеры, рекомендуемый контекст, рекомендуемый размер ответа, количество Regex и наличие дополнительных данных.

После этого нажмите «✅ Сохранить» или «❌ Отмена».

До подтверждения ничего в вашу библиотеку не сохраняется.

Импорт и сохранение пресетов доступны во время пробного периода и с Premium.

После сохранения пресет появляется в /preset.

Пресет сохраняется один раз

Как и карточки персонажей, пресеты хранятся в вашей коллекции.

Не нужно заново загружать JSON в каждую историю. Импортировали один раз — дальше можете использовать его в разных Темах.

Как включить пресет

Откройте нужную Тему и отправьте /preset.

Вы увидите свою коллекцию. Рядом с нужным пресетом нажмите ▶️.

Пресет включится только для этой Темы.

В разных Темах можно использовать разные пресеты: одна история — Gemini с литературным пресетом, другая — Claude с пресетом для диалогов, третья — какой-то ещё. Настройка не распространяется автоматически на все истории.

Как понять, какой пресет активен

В /preset активный будет отмечен ✅. Рядом появятся ⚙️ (управление блоками) и ⏹ (выключение).

Как выключить пресет

Откройте /preset и нажмите ⏹.

Пресет перестанет использоваться в этой Теме. Его JSON останется сохранённым в вашей библиотеке, и его можно включить снова позже.

Что происходит с настройками генерации после выключения

При включении пресета Limerence применяет его поддерживаемые сэмплеры. При выключении они снимаются.

Для Temperature Limerence отдельно запоминает предыдущее значение и старается вернуть его.

Другие сэмплеры пресета сбрасываются обратно к обычным настройкам и значениям по умолчанию.

Поэтому если до пресета вы вручную выставляли сложную комбинацию вроде Top P + Presence + Frequency и хотите потом воспроизвести её точно, имеет смысл помнить свои значения.

Безопасность и хранение

Что Limerence делает с API-ключами внутри чужого файла

Пресет не должен заменять ваш API-провайдер чужим.

При импорте Limerence удаляет из сохраняемого preset JSON известные поля, которые могут содержать reverse proxy, proxy password, custom URL, API-ключи и другие похожие секреты подключения.

Используется ваш собственный настроенный провайдер Limerence.

То есть скачанный JSON не должен незаметно принести с собой чужой API-ключ или переключить вас на чужой proxy.

Как хранятся сохранённые пресеты

Содержимое импортированного пресета хранится в зашифрованном виде.

Это особенно важно, потому что внутри могут находиться большие авторские системные промпты и jailbreak-инструкции.

Для списка Limerence отдельно хранит только необходимые служебные данные вроде названия и краткой информации о пресете.

Что происходит, если импортировать обновлённую версию того же пресета

Пресет идентифицируется в коллекции в том числе по имени.

Если импортируется обновлённый файл с тем же сохранённым названием, Limerence может обновить существующую запись вместо создания ещё одного одинакового пресета.

Поэтому авторские обновления удобно переимпортировать.

Если хотите хранить две версии отдельно, дайте файлам или пресетам разные названия.

Как удалить пресет

Откройте /preset и нажмите 🗑.

Limerence попросит подтверждение. Удаление самого сохранённого пресета необратимо.

Если пресет сейчас активен в важной Теме, безопаснее сначала выключить его через ⏹, а уже потом удалять из библиотеки.
